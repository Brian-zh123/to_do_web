# 校园代办 · Campus Concierge

把一段冗长的校园通知，变成一张能勾选的待办清单。

粘贴通知后，页面会自动提取四个关键字段：

- **什么事**：活动 / 事务名称
- **什么时候截止**：截止日期、时间、相对剩余天数
- **要做什么**：按动作拆出的待办步骤
- **在哪办**：线下地点，或腾讯会议等线上方式

## 直接打开

这是一个纯静态网站，不需要安装依赖，也没有后端。

直接双击 `index.html` 即可；也可以在当前目录启动一个本地服务器：

```powershell
python -m http.server 4174 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:4174/>。

## 已实现的功能

- 中文通知规则解析：绝对日期、相对日期、星期、上午 / 下午时间、日期范围
- 区分「报名截止时间」与「活动开始时间」
- 识别提交、报名、填写、领取、参加、签到、缴费、携带等动作
- 4 个字段的覆盖率提示与识别依据
- 可勾选待办清单、进度条、手动补充待办、删除待办
- 自动保存在浏览器 `localStorage`
- 复制清单文本、导出 `.ics` 日历文件
- 最近 8 条解析历史
- 桌面 / 移动端响应式布局

## 文件结构

```text
index.html   页面结构
styles.css   视觉样式与响应式布局
parser.js    纯前端中文通知解析器
app.js       页面交互、状态管理与本地保存
```

## 识别边界

`parser.js` 使用的是可解释的本地规则，不调用大模型或服务器：

- 支持「11 月 3 日」「2026 年 12 月 1 日」「本周五」「下周一」「今天 / 明天」等常见写法；
- 没有明确截止时间时，会把活动时间标成「关键时间」并提示是推断结果；
- 如果通知里有多段日期，会优先选择带「截止 / 之前 / 请于」等上下文的一项；
- 重要通知仍建议对照原文，或向发布方确认。

## 隐私

通知原文、解析结果和清单状态都只保存在当前浏览器，不会上传。
